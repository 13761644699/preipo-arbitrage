# 盘前股权合约套利看板 · Pre-IPO Equity Contract Arbitrage Dashboard

把**盘前股权（pre-IPO）合约**在各家交易所的报价拉到一起，按统一口径换算成**隐含市值**，再算出跨所价差与跨所资金费差 —— 让你一眼看出「哪两条腿可比、差多少、扣掉手续费还值不值得动」。

覆盖标的：**SpaceX / OpenAI / Anthropic** 的估值合约，以及 SPCX、OPN 等映射标的。

> ⚠️ **免责声明**：本项目是**数据聚合与口径统一工具**，**不构成任何投资建议**。
> 看板给出的「可做 / 观察 / 不可做」只是**人工复核优先级**，不是自动套利信号。
> 盘前股权合约是新品类，流动性薄、定价机制不透明、可能被交易所单方面调整规则或下架，
> 风险极高。所有报价均来自第三方公开接口，可能延迟或失真，**动手前请自行复核**。
> 使用本项目造成的任何后果由使用者自行承担。

---

## 功能

- **统一口径换算隐含市值**：不同交易所对同一标的用不同报价单位（估值指数、代理股价、代理代币价），看板按显式公式全部折算成隐含市值（B USD）后再比，**公式写在页面上，不藏在标签里**。
- **跨所价差**：同一标的在不同交易所的隐含市值价差，扣除默认往返手续费后给出「粗扣费后」结果。
- **跨所资金费差**：同一标的各交易所永续合约的资金费，换算成统一 APY 口径后比较。
- **映射标的单独观察**：SPCX、OPN 这类映射标的**只和同口径的映射标的比，不和估值合约硬混**，避免把不同东西算成一个价差。
- **拿不到数据就说拿不到**：接口失败、只有单边报价、缺少可比双边时，明确写「不可做 / 只有单边 / 暂无可比价差」，**不做 0 填充、不硬凑结论**。

| --- | --- | --- |
| Binance | `fapi.binance.com` | 盘前合约报价、资金费 |

## 快速开始

只需要 **Python 3.10+**（用到了 `datetime.UTC`），**无任何第三方依赖**：

```bash
python run.py
```

生成后会自动用浏览器打开看板。不想自动打开：

```bash
python run.py --no-open
```

## 口径与分级

### 隐含市值换算

| 报价类型 | 公式 |
| --- | --- |
| 估值指数（`valuation_index_10x`） | 价格 **× 0.1** = 隐含市值（B USD） |
| 代理股价（`proxy_share_price`） | 价格 **× 1.2** = 隐含市值（B USD） |
| 代理代币价（`proxy_token_price`） | 价格 **× 1000** = 隐含市值（B USD） |

### 分级阈值

| 维度 | 可做（强） | 观察 | 薄 |
| --- | --- | --- | --- |
| 价差 | ≥ **1.0%** | ≥ 0.35% | > 0% |
| 资金费差 | ≥ **30% APY** | ≥ 12% APY | ≥ 5% APY |

默认往返手续费：**0.16%**（`DEFAULT_ROUND_TRIP_FEE_PCT`），可在源码里调整。

## 设计原则

1. **口径先统一，再比较。** 不同报价单位必须显式折算，绝不直接混算。
2. **映射标的与估值合约隔离。** 两套口径分开呈现，避免制造假价差。
3. **缺数据就承认缺数据。** 只有单边、接口报错时如实标注，不填充、不猜测。
4. **结论偏保守。** 宁可说「不可做」，也不给一个看起来很诱人但站不住的机会。

## Roadmap

以下场所在源码中以「待接入源位」形式列出，**尚未接入**（多数只有网页/登录数据，没有稳定公开行情 API）：

- PreStocks、Jarsy、MSX、Deshare —— 私人股权交易场所，待确认公开 API
- Ondo GM —— tokenized stock/RWA，需先确认合约地址与价格源
- Republic —— 偏一级/私募市场报价，**不能与永续盘前合约直接混算**
- Binance Wallet / OKX Wallet —— 链上映射标的，需明确链、合约地址、池子与份额口径
